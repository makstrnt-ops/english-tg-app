# English Trainer — Telegram Mini App

Лёгкое мини-приложение для прокачки английского. Без сервера и сборки: 4 статичных файла.

## Что внутри

**Урок дня** в стиле Duolingo. Это смешанная сессия минут на 5: знакомство с новыми словами, повторение тех, у которых подошёл срок, пары, буквы, сборка фразы, диктант, вопрос по грамматике и неправильный глагол. Ошибки повторяются в конце урока, есть комбо-счётчик и итоги с конфетти.

Тренажёры:

| Режим | Откуда идея | Суть |
|---|---|---|
| Карточки | Anki | Интервальное повторение (SM-2) с оценками «не помню / сложно / помню / легко» |
| Пары | Quizlet, Duolingo | Найди 5 пар «слово — перевод» на время |
| Спринт | Lingualeo | 60 секунд: перевод верный или нет, множитель до ×4 |
| Саванна | Lingualeo | Слово падает, успей выбрать перевод; 5 жизней |
| Аудиовызов | Lingualeo | Узнай слово на слух |
| Конструктор | Lingualeo | Собери слово из букв |
| Собери фразу | Duolingo | Переведи предложение, нажимая на плитки со словами |
| Диктант | Duolingo, Puzzle English | Запиши фразу, которую слышишь (есть замедленное воспроизведение) |
| Правописание | Memrise | Напиши слово, прощаются мелкие опечатки |
| Диалоги | Babbel, Busuu | Выбери подходящую реплику в живой ситуации (8 сценариев) |

Плюс:
- **Грамматика**: 13 тем с теорией, 72 вопроса с объяснениями.
- **Неправильные глаголы**: 81 глагол.
- **Словарь**: свои слова, поиск по базе, «трудные» слова.
- **Прогресс**: уровень игрока, серия, рекорды, график.

**Озвучка** использует встроенный синтезатор устройства и автоматически выбирает самый качественный английский голос (Natural, Neural, Premium, Enhanced, Siri, Google). Голос и скорость речи можно поменять в настройках.

**Контент**: 361 слово A1–B2, 75 фраз, 8 диалогов.

Прогресс хранится в Telegram CloudStorage и синхронизируется между устройствами. В обычном браузере он сохраняется в localStorage.

## Запуск за 10 минут

### 1. Хостинг (GitHub Pages, бесплатно)
1. Создай публичный репозиторий на github.com, например `english-tg-app`.
2. Залей туда `index.html`, `app.js`, `data.js`, `style.css`.
3. Открой Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
4. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/english-tg-app/`.

Подойдёт любой HTTPS-хостинг: Netlify Drop, Vercel, Cloudflare Pages.

### 2. Бот
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` и создай бота.
2. `/mybots` → твой бот → **Bot Settings → Menu Button → Configure menu button**. Пришли URL из шага 1 и название кнопки, например «Учить».
3. Открой бота, и слева от поля ввода появится кнопка запуска.

Ещё можно создать прямую ссылку `t.me/<бот>/<app>` через команду `/newapp` в BotFather.

> Боту не нужен сервер: кнопка меню просто открывает страницу. На `/start` он отвечать не будет, пока не напишешь для него код.

## Как добавить контент

Всё лежит в `data.js`:
- слова: строка `english|перевод|пример` в нужном уровне;
- глаголы: `V1|V2|V3|перевод` (варианты через `/`, например `learnt/learned`);
- грамматика: `[предложение с ___, [варианты], индекс_верного, объяснение]`;
- фразы: `english|перевод` в нужном уровне;
- диалоги: `['them', фраза, перевод]` или `['me', [верный, неверный, неверный], перевод]`.

## Локальная проверка

Открой `index.html` в браузере, интернет и сервер не нужны.
